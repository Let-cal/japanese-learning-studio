# Japanese Learning Studio

An owner-focused Japanese vocabulary and Kanji learning application in preparation.

**Status:** Task 0 foundation and compatibility evaluation. Product implementation, deployment and learning features are not available yet. No CI or browser compatibility claim is made by this repository.

The approved direction is a Next.js/TypeScript application with separate recall evidence for meaning, kana and Kanji recognition, FSRS scheduling, private media and recoverable study data. A future public demo will use isolated sample fixtures without personal data or live provider credentials.

Hosting, services and AI must remain **USD 0**. Paid upgrades, provider substitutions and production releases require separate review.
